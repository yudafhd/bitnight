# Sword Atelier

Interactive procedural 3D sword gallery built with Three.js.

## Features

- Three procedural swords: wood, iron/steel, and cyber sword
- Click or tap a sword to swing it forward
- Drag the empty canvas area to rotate the view
- Procedural Web Audio swing sounds
- Historical context panel for the wooden and medieval-inspired swords
- Fictional lore panel for the cyber sword
- Responsive desktop and mobile layout

## Run locally

Serve this directory with any static web server. The Three.js WebGPU module is loaded from jsDelivr and falls back to WebGL 2 when supported by the browser.
